## Update wmacevoy.github.io Schedule (via Claude Code)

This is separate from the F:/public\_html CMU homepage below — it's the personal Next.js site in the `wmacevoy.github.io` repo (this repo), deployed to GitHub Pages. Claude Code can update it directly:

1. Open a Claude Code session in the `wmacevoy.github.io` repo.
2. Give it your office hours for the semester (e.g. "my office hours are Mon 9-10:50am, Wed/Fri 9-9:50am, Thu 11-11:50am, no office hours Tuesday") and ask it to update the schedule on the home page.
3. Give it the current semester's course list from "Determine Semester Classes" above (course #/title, days, times, room), and ask it to update the schedule with the new semester's courses.
4. If you also have the syllabus (Google Doc), D2L, and GitHub repo links for each course, give those too and ask it to add Syllabus/Assignments/Repo links to each course's schedule entry.
5. Claude Code edits `pages/components/schedule.js` (and `lib/schedulebuilder.js` if the rendering itself needs to change) and runs a local `next build` to check for errors before anything goes live.
6. When you're ready to go live, tell it "publish please" — it runs `npm run deploy`, which rebuilds and pushes the `out/` folder to the `gh-pages` branch (the live site). This is separate from committing the source edits to git — mention if you also want those committed/pushed to the working branch.
